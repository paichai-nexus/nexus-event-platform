# Project Documentation

이 디렉터리는 NEXUS Event Platform의 요구사항, 개발, 운영과 결과 기록을 관리합니다.

## 현재 문서

- [TEAM.md](./TEAM.md): 프로젝트 담당자, 책임 범위와 의사결정 방식
- [DEVELOPMENT_PLAN.md](./DEVELOPMENT_PLAN.md): MVP 범위, 기술 기준, 구현 순서와 완료 조건
- [CONTRIBUTING.md](../CONTRIBUTING.md): Issue, Branch, Commit, Pull Request와 리뷰 규칙

## 추가 예정 문서

- `REQUIREMENTS.md`: 경영대학 승인 사항을 반영한 최종 요구사항
- `ARCHITECTURE.md`: 시스템 구성도, 데이터 흐름과 권한 구조
- `DATA_MODEL.md`: 테이블 관계와 보관·삭제 정책
- `TEST_PLAN.md`: 기능·통합·현장 리허설 테스트
- `OPERATIONS.md`: 행사 당일 운영과 장애 대응 절차
- `meeting-notes/`: 회의 결정 사항과 후속 업무
- `results/`: 행사 종료 후 비식별 운영 결과와 회고

## 문서 관리 원칙

- 확정된 내용과 제안 중인 내용을 구분합니다.
- 규정, 일정 또는 평가식 변경 시 근거와 날짜를 기록합니다.
- 개인정보와 실제 평가 원자료는 공개 저장소에 올리지 않습니다.
- 구현 변경이 문서에 영향을 주면 같은 Pull Request에서 함께 수정합니다.
